# 🎮 2D Game Engine

Дипломный проект | Разработка легковесного игрового движка с компонентной архитектурой и системой сцен для создания 2D-проектов.

---

## О проекте

Данный движок представляет собой программную среду для разработки 2D-игр. 
Он предоставляет разработчику набор инструментов для управления игровыми объектами, 
сценами и взаимодействиями без необходимости писать сложный низкоуровневый код.

**Цель проекта:** Создание легковесного и интуитивно понятного 2D-движка 
для быстрой разработки игровых прототипов.
---
## Возможности
### Система сцен
- Создание и переключение между игровыми сценами
- Управление объектами внутри сцены
- Гибкая архитектура для построения игровых уровней
### Работа с объектами
Движок предоставляет следующие функции для управления объектами:
| Функция | Описание |
|---------|----------|
| `add_object` | Создание нового объекта в сцене |
| `del_object` | Удаление объекта из сцены |
| `set_pos` | Установка позиции объекта (x, y) |
| `smooth_set_pos` | Плавное перемещение объекта в заданную позицию |
| `get_object_pos` | Получение текущей позиции объекта |
| `set_size` | Изменение размера объекта |
| `get_size` | Получение размера объекта |
| `set_sprite` | Назначение спрайта (графического изображения) объекту |
| `rotate` | Вращение объекта на заданный угол |
| `get_rotate` | Получение текущего угла поворота объекта |
| `get_rotate_to` | Вычисление угла поворота к целевой точке |
### Взаимодействие с пользователем
| Функция | Описание |
|---------|----------|
| `is_pressed` | Проверка нажатия на определённую клавишу клавиатуры |
| `go_to_mouse_x` | Получение X-координаты курсора мыши |
| `go_to_mouse_y` | Получение Y-координаты курсора мыши |
### Звук
| Функция | Описание |
|---------|----------|
| `play_sound` | Воспроизведение звукового эффекта |
### Управление сценами
| Функция | Описание |
|---------|----------|
| `change_scene` | Переключение на другую игровую сцену |

## Установка и запуск

### Скачивание
Скачайте архив `Engine.zip` с GitHub:
  https://github.com/VeRnEmO-OFF/Engine

### Распаковка
Распакуйте архив в любую папку на вашем компьютере.

### Запуск
- Запустите файл `Main.py`
- В открывшемся окне нажмите на название тестового проекта и после нажмите кнопку **"Играть"**

### Изменение скриптов и сцен
- для изменения скриптов меняйте содержимое файлов *.py в соответствующих директориях сцен 

### Возможные проблемы при запуске
Если игра не запускается, установите Pygame вписав в терминал проекта pip install pygame

```python
set_sprite(name='player', sprite="player")

# Плавное перемещение к курсору реализуется через цикл
while True:
    if get_var(SESSION_PATH, "change_scene_to") != "None":
        break
  smooth_set_pos('player', go_to_mouse_x(), go_to_mouse_y())
```
